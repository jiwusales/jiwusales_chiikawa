圖鑑管理安全設定

在手機完成授權與設定，再把加密檔傳回原對話。

正在準備安全設定…

1先填入權杖與管理密碼

先備妥這些內容，再開啟下一步授權。切換到授權分頁時，這些輸入會保留在本頁。

2開啟 Cloudflare 授權

開啟 Cloudflare 授權 ↗

授權完成後，如果手機顯示「localhost 無法連線」，請複製瀏覽器的完整網址，立即回本頁貼在下一步。

3貼回完整網址並加密下載

管理密碼會在本機轉成雜湊；授權網址、權杖與密碼雜湊會在本機加密。本頁不會上傳或儲存這些輸入內容。

4把加密檔傳回原對話

請將剛下載的 jiwu-catalog-setup.encrypted.json 以附件傳回原對話。

這份加密檔可以安全傳回，只有持有此次設定私鑰的一方能解開。輸入欄位已清空，請直接傳檔案，無須貼上授權網址、權杖或密碼。

再次下載加密檔
一次性設定連結有使用期限。此頁只讀取公開加密設定，所有敏感資料都在目前瀏覽器內處理。
